## 🌐 Supported Platforms

| Platform | Features & Metrics Extracted |
|---|---|
| **⚡ LeetCode** | Problems Solved (Easy / Medium / Hard rings), Acceptance Rate, World Rank, Contest Rating, Top %, Official **🛡️ Guardian** & **⚔️ Knight** Badges, Real Profile Avatar, Socials |
| **🔺 Codeforces** | Current Rating, Max Peak Rating, Official Rank Tiers (*Legendary Grandmaster, Master, Candidate Master, Expert, Specialist, Pupil, Newbie*), Contribution Points, Friend Count, Organization, Country & City, Title Avatar |
| **👨‍🍳 CodeChef** | Live Rating, Star Level (1★ to 7★), Peak Rating, Global & Country Ranks, User Category (Student/Professional), University/Institution |

## ✨ Features

- 🎛️ **Custom Cyber Dropdown**: Switch seamlessly between LeetCode, Codeforces, and CodeChef. Automatically adapts input placeholders, hot picks, and dashboard visualizations.
- 🖼️ **Real Profile Avatars**: Fetches actual coder profile photos with glowing cyber-neon borders and graceful fallback initials.
- 🏆 **Contest Analytics & Rank Tiers**: Live competitive ratings, peak scores, and official rank badges across all platforms.
- 🔮 **Gen-Z Cyber-Glass Aesthetic**: OLED dark mode with ambient glow orbs, specular gradients, frosted glass panels (`backdrop-filter: blur(20px)`), and micro-animations.
- ⚡ **Dynamic Aura Rank & Score**: Automatically calculates custom aura titles (*👑 Legendary Titan*, *👑 LeetCode Guardian God*, *🔥 Grandmaster Demon*, *⚔️ Code Knight*, *🌱 Rising Coder*) per platform.
- 📊 **Animated SVG Progress Rings**: Real-time animated stroke-dashoffset rings with glowing drop-shadows.
- 🔢 **Animated Count-Up Numbers**: Smooth numeric counter transitions for solved problems, ratings, and ranks.
- 🚀 **One-Click Share & Copy**: Formats and copies a platform-tailored Discord/Twitter/LinkedIn-ready stats card summary to your clipboard.
- 🕒 **Platform-Isolated Search History**: Remembers your recent searches independently for each platform in `localStorage`.
- 🛡️ **Bulletproof Error Resilience**: Graceful error handling for missing handles, API timeouts, and network drops with toast notifications.
- 📱 **100% Mobile Responsive**: Looks breathtaking on phones, tablets, laptops, and ultra-wide displays.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup with custom ARIA dropdown
- **CSS3**: Vanilla modern CSS with CSS variables, Glassmorphism, CSS Grid & Flexbox, SVG filter glows
- **JavaScript**: Pure ES6+ (`Promise.allSettled`, Fetch API with AbortController, SVG DOM manipulation, Clipboard API, LocalStorage)
- **APIs**:
  - [Tashif LeetCode Stats API](https://github.com/JeremyTsaii/leetcode-stats-api) & [Alfa LeetCode API](https://github.com/alfaarghya/alfa-leetcode-api) (LeetCode)
  - [Official Codeforces API](https://codeforces.com/api/help) (Codeforces)
  - [CompeteAPI](https://github.com/ravibabuvadde/competeapi) (CodeChef)

## 🚀 Getting Started

No build tools, Node modules, or bundlers required! Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
